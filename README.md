# Clearpath

Clearpath face vizibilă experiența reală a utilizatorilor cu deficiențe de vedere pe orice site web. Pornind de la un simplu link, platforma analizează cum este percepută navigarea prin tehnologii asistive și livrează o înregistrare în care se vede și se aude efectiv parcurgerea site-ului, alături de concluziile analizei.
