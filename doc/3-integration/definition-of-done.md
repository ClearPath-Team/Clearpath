# MVP Definition of Done

- [ ] On a clean laptop, following `doc/setup/setup.md` and launching `python scripts/dev.py` brings up all services without Docker.
- [ ] Submitting a URL produces, in under 3 minutes:
  - a synchronized narrated video clip;
  - an organized issue list with clickable timestamps;
  - a calculated accessibility score (0–100);
  - actionable recommendations.
- [ ] Clicking any timestamp jumps the video player directly to that moment in the clip.
- [ ] Each analysis receives a distinct shareable URL that loads independently across browser tabs.
- [ ] The presentation demo can run entirely offline without internet access (`doc/3-integration/demo.md`).
- [ ] All acceptance criteria defined across the 4 member tracks in `doc/2-tracks/` are fulfilled.
